# Generador de Colores

Generador de paletas de colores aleatorias que funciona en el navegador. Hecho con HTML, CSS y JavaScript puro, sin librerías.

## Cómo probarlo

Clona el repositorio y abre `index.html` en el navegador.

## Qué practiqué

- Manipulación del DOM con JavaScript
- Estilos con CSS
